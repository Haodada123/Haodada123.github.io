Research Experience

Leakage Analysis and Attacks on Encrypted Search

Jigsaw — USENIX Security 2024; Peekaboo — ACM CCS 2025

  • Investigated how observable leakage from searchable encryption, including access, volume, search, and file-volume patterns, can be exploited to recover sensitive search queries.
  • Developed Jigsaw, an easy-to-hard query-recovery attack that first identifies distinctive queries using volume and frequency information and then progressively recovers the remaining queries through co-occurrence relationships.
  • Extended leakage-abuse analysis to dynamic searchable encryption with Peekaboo, introducing intermittent-observation attacks that infer search patterns across disconnected observation periods and enable effective query recovery without continuous leakage monitoring.

Leakage-Resilient Encrypted Databases

Aspire — NDSS 2027, Accepted

  • Introduced restricted zero-leakage, a practical security notion that eliminates plaintext-dependent semantic leakage while allowing non-semantic operation metadata.
  • Designed Aspire, a dynamic encrypted key-value database that combines probabilistic batch codes, minimal perfect hashing, and oblivious data access to support efficient batch keyword queries and dynamic updates under restricted zero-leakage.
  • Implemented and evaluated Aspire on databases with up to millions of key-value pairs, achieving an amortized query latency below 1.38 ms while substantially reducing communication overhead for large batch queries.

Privacy-Preserving Data Trading

Innovation Research Project in Collaboration with Ant Group

  • Study efficient cryptographic protocols for privacy-preserving data trading, with a focus on controlled data retrieval and secure data delivery with billing support.

Ongoing Research

  • Constant-Communication Access-Pattern Hiding. Explore efficient encrypted retrieval mechanisms that hide access patterns with constant communication overhead.
  • High-Concurrency Private Information Retrieval. Develop efficient PIR protocols for multi-user concurrent queries, focusing on improving scalability under high query concurrency.
  • Query Recovery with General Knowledge. Develop leakage-abuse attacks that reduce dependence on large target-related auxiliary datasets by exploiting general knowledge for encrypted query inference.
